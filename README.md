# java-calculator-precourse

## 구현할 기능 목록
### 값 입출력하기
- [ ] `camp.nextstep.edu.missionutils.Console`의 `readLine` 메서드를 사용해 값을 입력받는다.
- [ ] 값을 입력받아야 할 때 `덧셈할 문자열을 입력해 주세요.`라는 안내 문구를 출력한다.
- [ ] 계산 결과를 `결과 : ${계산 값}` 형식으로 출력한다.

### 입력된 값 검증하기
- [ ] 입력 값이 존재하는지 검증한다.
- [ ] 구분자(커스텀 구분자 포함)와 숫자를 제외한 문자가 포함되지 않았음을 검증한다.
- [ ] 커스텀 구분자가 지정되었는지 확인하고, 지정되었을 경우 구분자에 포함한다.

### 계산하기
- [ ] 구분자를 기능으로 분리된 각 숫자의 합을 반환한다.
